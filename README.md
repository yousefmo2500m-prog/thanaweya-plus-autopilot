# 🚀 ثانويتي بلس — المحرك الذاتي الشامل للنشر اليومي (الإصدار الاحترافي v3)

نظام مستقل تماماً (**0 جنيه للأبد**) مصمم خصيصاً بهوية وشعار ومحتوى منصة **ثانويتي بلس** (`https://thanaweya-ashy.vercel.app`) لنشر محتوى تعليمي حقيقي ومفيد ومفصّل **3 مرات يومياً** على المنصات الأربعة (**فيسبوك + إنستجرام + يوتيوب شورتس + تيك توك**) مع وضع رابط المنصة تلقائياً في **أول تعليق**.

---

## ✨ ماذا يميز الإصدار الجديد (v3)؟

1. **تغطية شاملة ودقيقة 100% لمنهج 2026 / 2027 والمنصة الفعلية**:
   - **بطاقة (1/4) — الصف الأول الثانوي**: السنة التأسيسية الموحدة (عام وبكالوريا مصرية: علوم متكاملة، تاريخ مصري، رياضيات، عربي، إنجليزي، فلسفة ومنطق، برمجة وذكاء اصطناعي).
   - **بطاقة (2/4) — الصف الثاني الثانوي (البكالوريا المصرية بمساراتها الـ 4 كاملة)**:
     - المواد الأساسية المشتركة (اللغة العربية، اللغة الإنجليزية، التاريخ المصري).
     - **1) مسار الطب وعلوم الحياة**: الفيزياء أو الرياضيات.
     - **2) مسار الهندسة وعلوم الحاسب**: الكيمياء أو البرمجة والذكاء الاصطناعي.
     - **3) مسار الأعمال**: المحاسبة أو إدارة الأعمال.
     - **4) مسار الآداب والفنون**: علم النفس أو اللغة الأجنبية الثانية.
   - **بطاقة (3/4) — الصف الثاني الثانوي العام**: الشعبة العلمية + الشعبة الأدبية.
   - **بطاقة (4/4) — الصف الثالث الثانوي**: مشترك علمي + علمي علوم (ومسار الطب المتقدم) + علمي رياضة (ومسار الهندسة المتقدم) + الشعبة الأدبية (ومساري الأعمال والآداب).
2. **تحديد دقيق لكل تفصيلة بدون أي مصطلحات مبهمة**:
   - كل مادة في الجدول والملخص والأسئلة مكتوب أمامها بوضوح: **الوحدة / الباب الكام + الدرس الكام + الجزء الكام (`الجزء ١ من ٢` / `الجزء ٢ والأخير` / `الدرس كامل`) + خطوات المذاكرة والتطبيق العملي بالأمثلة والقوانين** (تم إلغاء كلمة «بومودورو» تماماً).
   - متزامن تلقائياً مع التقويم الفعلي لوزارة التربية والتعليم المصرية 2026 / 2027 (أيام التقييمات الأسبوعية، امتحانات الشهور، مراجعات نصف وآخر العام).
3. **هوية وشعار «ثانويتي بلس» الرسمي**:
   - البطاقات الأربعة (`1080×1350`) وفيديوهات الريلز/الشورتس (`1080×1920`) وفيديو تحدي الـ 30 ثانية مصممة بألوان الموقع الرسمية (`#0b1020`, `#2dd4bf`, `#8b5cf6`, `#fbbf24`) وشعار البومة الرسمي (`assets/logo.png`).
4. **الرابط المباشر في أول تعليق (`first_comment`)**:
   - البوست الأساسي على فيسبوك نظيف تماماً من الروابط الخارجية (لمضاعفة الوصول الطبيعي Reach)، وبمجرد نشر البوست أو الفيديو يقوم النظام بوضع تعليق فوري يحتوي على الرابط القابل للضغط `https://thanaweya-ashy.vercel.app`.

## 🛠️ طريقة التحديث أو التركيب (في 3 دقائق فقط)

### أولاً: تحديث ملفات GitHub
ارفع الملفات المحدّثة داخل المستودع الخاص بك على GitHub (أو فك ضغط `thanaweya-autopilot.zip` وارفع محتوياته):
- `assets/logo.png` (شعار ثانويتي بلس الرسمي — مهم جداً!)
- `curriculum_2026_2027.py`
- `studio_renderer.py`
- `autopilot.py`
- `fonts/Cairo-Variable.ttf`
- `requirements.txt`
- `.github/workflows/daily_autopilot.yml` *(تأكد من وجوده في المسار `.github/workflows/daily_autopilot.yml`)*

وتأكد من وجود المفتاحين في **Settings → Secrets and variables → Actions**:
1. `GROQ_API_KEY`: مفتاح Groq المجاني الخاص بك.
2. `MAKE_WEBHOOK_URL`: رابط الـ Webhook من الدائرة رقم (1) في Make.com.

### ثانياً: استيراد البلوبرنت المحدّث في Make.com + أول تعليق
1. افتح السيناريو في **Make.com** ومن الثلاث نقاط السفلية `(...)` اختر **Import Blueprint** وارفع ملف:
   `ثانويتي بلس - الناشر الرباعي المستقل للأبد.blueprint.json`
2. ستجد السيناريو جاهزاً بـ **10 دوائر ذكية** (يستهلك **651 عملية فقط شهرياً** من أصل 1000 عملية مجانية):
   - **دائرة (4) + دائرة (9)**: تنشر ألبوم الـ **4 بطاقات** على صفحة فيسبوك ثم تضع الرابط `https://thanaweya-ashy.vercel.app` تلقائياً في **أول تعليق**!
   - **دائرة (5) + دائرة (10)**: تنشر فيديو تحدي الـ **30 ثانية** بليل على صفحة فيسبوك ثم تضع الرابط تلقائياً في **أول تعليق**!
   - **دائرة (6)**: تنشر الـ Reel على **إنستجرام**.
   - **دائرة (7)**: تنشر الفيديو على **YouTube Shorts**.
   - **دائرة (8)**: تنشر الفيديو على **TikTok** عبر Zernio مجاناً.

### ثالثاً: ملاحظة مهمة بخصوص «أول تعليق» في إنستجرام ويوتيوب وتيك توك
- **فيسبوك**: مدمج ومفعّل تلقائياً داخل ملف البلوبرنت (الدائرتان 9 و10)، والرابط فيه قابل للضغط فوراً.
- **إنستجرام (اختياري بضغطة واحدة)**: يمكنك الضغط على علامة `+` بعد دائرة إنستجرام (6) واختيار **Instagram for Business → Create a comment**:
  - في حقل `Media ID`: اختر `6. Media ID`
  - في حقل `Message`: اختر `1. first_comment`
  *(تنبيه تقني من ميتا: إنستجرام لا يجعل الروابط قابلة للضغط داخل التعليقات أو الكابشن، لذا ضع أيضاً رابط `https://thanaweya-ashy.vercel.app` في خانة Website في بايو حساب إنستجرام).*
- **يوتيوب شورتس (اختياري بضغطة واحدة)**: الرابط يوضع تلقائياً في أول سطر من وصف الفيديو، وإذا أردت نشره أيضاً كأول تعليق على الـ Short، اضغط `+` بعد دائرة يوتيوب (7) واختر **YouTube → Make an API Call**:
  - `URL`: `/v3/commentThreads?part=snippet`
  - `Method`: `POST`
  - `Body`:
    ```json
    {
      "snippet": {
        "videoId": "{{7.id}}",
        "topLevelComment": {
          "snippet": {
            "textOriginal": "{{1.first_comment}}"
          }
        }
      }
    }
    ```
    *(يتطلب منح صلاحية `https://www.googleapis.com/auth/youtube` عند ربط قناة يوتيوب).*
- **تيك توك**: واجهة برمجة تطبيقات تيك توك الرسمية (`TikTok Content Posting API`) لا تسمح لأي أداة خارجية بنشر تعليقات آلياً، كما أن تعليقات تيك توك لا تدعم الضغط على الروابط؛ لذلك تم ضبط كابشن تيك توك والفيديو لتوجيه الطلاب مباشرة إلى الرابط في البايو واسم الموقع في أول سطر.
