# محرك "ثانويتي بلس" المستقل للأبد (2026/2027 وما بعدها — $0 مجاناً للأبد)

محرك نشر تعليمي ذاتي بالكامل لمنصة **[ثانويتي بلس](https://thanaweya-ashy.vercel.app)** يعمل تلقائياً **3 مرات يومياً** طوال العام الدراسي والسنوات القادمة بدون أي تدخل بشري وبدون أي اشتراكات مدفوعة:

1. **07:00 صباحاً (جدول ومهمة اليوم):** بطاقات ألبوم (1080×1350) + فيديو ريلز/شورتس (1080×1920) يحدد لطلاب **أولى وثانية وثالثة ثانوي (الثانوية العامة والبكالوريا المصرية)** الدرس أو الجزء المطلوب مذاكرته اليوم + عدد جلسات البومودورو + نسبة إنجاز خطة التقفيل.
2. **05:30 المغرب (كبسولة الملخص والقوانين):** بطاقات وفيديو ملخص القوانين والتريكات الامتحانية **لنفس دروس الصباح بالضبط** مع توجيه لكروت أنكي والمدرس الذكي.
3. **09:00 مساءً (سهرة تحدي الـ 30 ثانية):** فيديو عداد تنازلي حيّ (30 ثانية بالصوت وجرس النهاية) + أسئلة السهرة للصفوف الثلاثة **بدون كشف أي إجابة** لإشعال التعليقات، مع تخصيص **الخميس والجمعة للتقييمات الأسبوعية لوزارة التربية والتعليم** ونهاية كل شهر للاختبارات الشهرية.

## خطوات التشغيل لمرة واحدة فقط (5 دقائق — ثم انساه للأبد!)

### أولاً: تجهيز الناشر الرباعي في Make.com
1. افتح سيناريو جديد في **Make.com** ← اضغط `...` بالأسفل ← **Import Blueprint** ← ارفع ملف:
   `ثانويتي بلس - الناشر الرباعي المستقل للأبد.blueprint.json`
2. اضغط على **الدائرة رقم `1` (Webhooks)** ← اضغط **Add** ← اضغط **Save** ← اضغط **Copy address to clipboard** لنسخ رابط الـ Webhook.
3. اربط حساباتك في الدوائر الأربع بعد الموزع (فيسبوك مربوط جاهز بصفحة ثانويتي بلس، واختر حسابك في إنستجرام ويوتيوب و Zernio لتيك توك).
4. فعّل زر السيناريو بالأسفل إلى **ON** واضغط **Save**.

### ثانياً: رفع المحرك على GitHub المجاني للأبد
1. ادخل على حسابك في **GitHub.com** واضغط **New repository**:
   - الاسم: `thanaweya-plus-autopilot`
   - مهم جداً: اجعله **Public** (حتى تحصل على دقائق تشغيل غير محدودة مجاناً للأبد + روابط مباشرة للصور والفيديو لإنستجرام وتيك توك!).
   - اضغط **Create repository**.
2. ارفع محتويات مجلد `thanaweya-autopilot` بالكامل داخل المستودع (تأكد من وجود مجلد `.github/workflows/daily_autopilot.yml` وملف `fonts/Cairo-Variable.ttf`).
3. داخل المستودع في GitHub افتح **Settings** ← من القائمة اليسرى اختر **Secrets and variables** ← **Actions** ← اضغط **New repository secret** وأضف سرّين فقط:
   - السر الأول:
     - **Name:** `GROQ_API_KEY`
     - **Secret:** مفتاح Groq الخاص بك (`gsk_...`)
   - السر الثاني:
     - **Name:** `MAKE_WEBHOOK_URL`
     - **Secret:** رابط الـ Webhook الذي نسخته من الدائرة رقم 1 في Make.com
4. افتح تبويب **Actions** بالأعلى ← اختر **Thanaweya Plus Daily Autopilot** ← اضغط **Run workflow** للتجربة الفورية، ومن بعدها سيعمل وحده تلقائياً الصبح والمغرب وبليل كل يوم مدى الحياة!
